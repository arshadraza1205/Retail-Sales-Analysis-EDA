# Retail Sales Analysis (Exploratory Data Analysis)

An Exploratory Data Analysis (EDA) project in Python analyzing retail transaction patterns, customer demographics, and product category performance.

## Project Overview
- **Dataset:** Retail Sales Dataset (1,000 transactions)
- **Tools Used:** Python, Pandas, Matplotlib, Seaborn, Google Colab

## Key Insights & Findings
- **Total Revenue:** $456,000.00 across 1,000 transactions
- **Average Order Value (AOV):** $456.00
- **Product Categories:** Analyzed revenue and sales volume across Electronics, Clothing, and Beauty
- **Demographics:** Customer spending segmented across age groups (18–25, 26–35, 36–50, 50+) and gender
- **Sales Trends:** Evaluated monthly fluctuations and seasonality across 2023

## Files in Repository
- `Retail_Sales_EDA.ipynb`: Complete Jupyter Notebook with code, data cleaning, and visualizations
- `retail_sales_dataset.csv`: Dataset containing transaction records
